# V6.5 Integration Specification

## Main model wire

Model Loader
 -> Dasiwa Hybrid Turbo v3 INT8
 -> existing LoRA(s)
 -> H3 Chunk FeedForward
 -> Veda Sparse Attention
 -> BasicGuider
 -> Sampler

Reason:
FFN is a model patch; Veda is the final attention override before the guider/sampler.

## Conditioning wire

Keep the V6.5 conditioning architecture.

reference / first-frame image
 -> ordinary H3 video VAE
 -> MiniMax H3 image/reference conditioning

Do not connect X2 Detail VAE here.

## Final output wire

Sampler latent
 -> H3 X2 Decode + Stream Save
 -> NVENC MP4
 + existing audio branch

Use a conventional H3 decoder as a bypass if downstream nodes need IMAGE frames.

## X2 VAE preparation

Input:
MiniMax-H3-X2-Detail-v1.safetensors

One-time conversion:
H3 X2 Prepare INT8 VAE

Output:
MiniMax-H3-X2-Detail-v1-decoder-int8-convrot.safetensors

The public converter validates the official source hash and quantizes 144 decoder Linear weights with INT8 ConvRot groupsize 256 while preserving the encoder, norms, biases and final FP16 X2 projection.

## Veda profiles

### Safe R2VA
generated_sparsity=90%
reference_sparsity=0%

### FL2VA starting point
generated_sparsity=90%
reference_sparsity=25-50%

### Speed experiment
generated_sparsity=90%
reference_sparsity=75-90%

Keep full_attention_layers and full_attention_steps empty initially.

## Do not stack sparse implementations

Use either Veda or the native H3 Model Sparse Attention path.
For this project use Veda.

Jev-SLA is retained as benchmark evidence and fallback comparison, not as a second sparse patch.

## 4-step / 8-step

4-step = production default.
8-step = quality fallback for difficult motion, multiple people, or unstable identity.

Veda's public predictor was trained around 8-step Turbo and selected resolutions/durations. Therefore Veda + Dasiwa 4-step is a local validation target, not a claimed upstream benchmark.

## A/B sequence

A0: Dasiwa + normal H3 VAE
A1: A0 + Veda
A2: A1 + FFN chunks=0
A3: A2 + INT8 H3 VAE / fp16 accumulation
A4: A3 + X2 INT8 VAE + async NVENC

Same prompt, resolution, frames, steps and seeds.

## RTX 3080 10GB

Veda's README lists SM80-SM89 support as code-path ready but not verified on RTX 30. Do not copy RTX 5070/4070 timing directly.

Use one H3 job at a time, aggressive ComfyUI offload, and avoid keeping large LLM/image models resident during generation.
