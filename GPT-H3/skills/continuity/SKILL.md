# Continuity

Carry across shot boundaries:
- character presence / absence
- terminal pose and gaze
- prop possession/state
- spatial landmark positions
- camera orientation/framing
- lighting direction
- emotional state
- dialogue/sound bridge
- next-shot opening target

Authority:
1. locked character card
2. locked scene card
3. latest approved shot row
4. latest approved storyboard section
5. rendered clip

When drift appears, strengthen the exact Reference Anchors before changing the model.
