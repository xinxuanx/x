# QA / Regression

Keep identical:
workflow version, prompt, references, resolution, frame count, seed, ComfyUI build, GPU.

Change one variable.

Record sampling time, VAE time, encode/save time, total wall time, VRAM peak, RAM peak and file size.

Inspect identity, eyes/mouth, hair, hands, props, scene landmarks, lighting, camera, motion, audio sync and shot handoff.

Statuses:
passed / failed / superseded / archived
